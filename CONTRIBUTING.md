# Feedback and contributions

BLCKSNAKE Command 1.0 is the first public release. Reports from real ARK installations will guide the next updates.

## Bug reports

Open an issue with:

- the BLCKSNAKE Command version;
- host operating system and Docker version;
- ARK server platform and map;
- the action you attempted;
- steps to reproduce the problem;
- what you expected and what happened; and
- a screenshot or short, sanitized error excerpt when useful.

Remove passwords, tokens, public IP addresses, player identifiers, private chat, and certificate or key material before posting. Use the private security-reporting route described in [SECURITY.md](SECURITY.md) for vulnerabilities or suspected credential exposure.

## Feature requests

Describe the server-management problem, who encounters it, and the result you need. Include the relevant ARK platform, hosting setup, or Discord workflow. A concrete use case is more useful than a proposed implementation.
