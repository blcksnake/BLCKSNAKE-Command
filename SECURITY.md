# Security policy

BLCKSNAKE Command supports the current 1.x release line.

Report vulnerabilities privately to the repository owner or deployment administrator. Include the affected version, impact, and reproduction steps using fake credentials. Do not open a public issue for a suspected vulnerability.

Never attach passwords, tokens, player identifiers, private chat, profiles, database or keystore copies, certificate keys, crash dumps, internal addresses, or unsanitized logs. Rotate any credential that may have been disclosed.

Deployment requirements and incident steps are documented in [docs/SECURITY.md](docs/SECURITY.md) and [docs/OPERATIONS.md](docs/OPERATIONS.md).
